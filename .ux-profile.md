# UX Profile

Generated by `setup-ui-ux-skills`. All UI/UX skills in this project read this file before changing layout, copy, or interaction.

## Aesthetic reference

- **Standard:** Custom, "Plum night" (Pocket Ledger's own look, not borrowed from another app)
- **Notes:** Keep the Coral Dusk colours and Nunito. The top of the Dashboard is a deep plum panel (a richer violet in dark mode) with the Budget Ring around "Left to spend this month"; Add is coral and Scan is soft and see-through. The sections below are white cards with big round corners that stack on top of each other as you scroll. The phone bar keeps 4 or 6 tabs, a bubble over the current tab, and a coral +. This replaces the old "calm white Left to spend card" rule.

## Banned anti-aesthetics

- Frosted-glass effects (blurry see-through panels)
- Rainbow or glowing gradients on buttons
- Small coloured pill badges for ordinary details
- Cartoon pictures on empty screens
- Jelly, bouncy or "cute" animations
- Emoji used as icons
- Thick coloured stripes down the side of cards
- Small all-capital labels above headings
- Boxes inside boxes

## Accessibility target

- **Level:** WCAG 2.1 AA
- **Contrast:** At least 4.5:1 for normal text, 3:1 for large text and borders
- **Touch / focus:** Tap targets of about 44px, clear focus rings, simple fades when reduce-motion is on

## Brand tone and microcopy voice

- **Voice:** Warm & Humancentric
- **Capitalization:** Sentence case for UI copy and buttons
- **Notes:** Plain English, short, kind. Buttons start with an action ("Add entry", never "OK"). Errors never blame the person and say what to do next. Dates are DD/MM/YYYY and money is in MVR.

## Icon library

- **Library:** Project SVG
- **Package / path:** The icon set inside `index.html` (`<symbol id="i-…">`, used with `<use href="#i-…">`)
- **Notes:** One set only. New icons are drawn in the same thin-line style. No emoji as icons.

## Agent rules

1. Read this profile before creating or editing any UI, CSS, or microcopy.
2. Prefer skills by task: new page → `page-patterns` (name the pattern before markup); layout / chrome → `viewports`; forms → `forms`; overlays → `surfaces`; loaders → `loaders`; empty views → `empty-states`; motion → `motion`. Before finishing UI, run `ux-audit`.
3. Use only the recorded icon library (or project SVG path). Do not mix icon sets or use emoji as UI icons.
4. Never introduce items on the banned list.
5. Destructive actions always use an explicit confirmation dialog.
